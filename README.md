**Pizza HUT**

Pizza Sales Analysis – Power BI Dashboard

**Project Overview**

This project analyzes pizza sales data to understand customer preferences, order patterns, and business performance.

The data was first cleaned using Microsoft Excel, then analyzed using MySQL for Exploratory Data Analysis (EDA), and finally visualized using Power BI to create an interactive dashboard.

The objective of this project is to generate insights that can help improve restaurant sales and decision-making.

**Project Objectives**

Calculate total revenue generated from pizza sales

Identify the highest-priced pizza

Find the most ordered pizza types

Analyze order distribution by day and month

Identify category-wise pizza sales

Determine top pizzas based on revenue

**Key Insights**

Veggie category pizzas generated the highest number of orders, indicating strong customer preference for traditional flavors.

Weekend sales were higher compared to weekdays, showing increased customer activity during leisure days.

Peak order hours occur during lunch and evening periods, indicating that demand is highest during typical meal times.
